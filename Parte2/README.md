# Calculadora en React

Se creó una calculadora simple usando React. La aplicación está dividida en componentes para mantener una estructura más ordenada:

- `App.jsx`: componente principal, maneja el estado de la calculadora y la lógica de los botones.
- `Display.jsx`: muestra en pantalla los números y resultados.
- `ButtonPanel.jsx`: contiene los botones de la calculadora.
- `App.css`: define los estilos visuales de la calculadora.
- `index.js`: inicia la aplicación y carga el componente `App`.

También se agregó el botón `AC`, que permite limpiar la pantalla de la calculadora.

## Funcionalidades

La calculadora permite realizar operaciones básicas como suma, resta, multiplicación y división. Además, muestra el resultado al presionar `=` y permite reiniciar la pantalla con `AC`.
